# IVCS Performance Tracking

Live dashboard for tracking daily IVCS registrations across Meghalaya, including district-wise, block-wise, IVCS-wise, and region-wise performance.

## Features

- Garo, Khasi, and Jaintia region views
- Registration targets and achievement
- District and block performance
- IVCS locations that have not started registration, with district names
- Manual data refresh
- Live server-side API integration

## Deploy on Netlify

Import this GitHub repository into Netlify. Netlify will detect the Next.js application automatically and run `npm run build`.
